# 余白设计 YUBAI STUDIO

一个「简约高级」风格的设计工作室官网（单页 HTML 网站）。

## 页面结构

- **Hero**：品牌标语「好的设计，始于克制。」
- **精选作品**：可交互作品索引（桌面端悬停预览 + 点击查看详情弹层）
- **服务范围**：品牌设计 / 空间设计 / 数字体验 / 艺术指导
- **关于工作室**：团队介绍与数据
- **联系**：项目合作入口

## 技术说明

- 单文件 HTML（内联 CSS / JS，无构建依赖）
- 字体：Noto Serif SC / Noto Sans SC / Cormorant Garamond（自托管镜像）
- 图片：编辑风格摄影，托管于稳定 CDN 链接
- 响应式：桌面 / 平板 / 移动端自适应，支持键盘操作与 `prefers-reduced-motion`

## 本地预览

直接使用浏览器打开 `index.html` 即可。

## 在线访问

启用 GitHub Pages（Settings → Pages → 选择 main 分支）后，即可通过仓库 Pages 地址访问。
